# 前期固定策略介入与独立Beam保护小试协议 v1

日期：2026-10-31。用户明确授权：先验证前期哪些搜索决策有收益，再调整PPO介入位置，保留Beam保底，做一轮小规模窗口、BC、PPO对照。本轮为已观察训练工况上的开发机制试验，不是正式泛化评价，不训练新模型，不保证必须胜出。

## 问题与事前选择

上一集成轮中，所有保护任务首次达到最终质量都在完整Beam阶段，后续学习器没有质量增量。旧S1和窗口教师也曾检验早期单步选择，不能把“前移”一概当作未测创新。本轮改变的是一个连续控制块：从搜索初始化后的第0次选择开始，由固定策略控制前16次扩展，此后统一使用当前窗口Beam规则直到原停止条件。它检验前期连续决策对后继前沿与完整认证收益的影响，不把父链相关性解释为某一个动作的独立因果效应。

16沿用旧有限分叉的16扩展观察尺度，并覆盖已观察窗口改进发生的第6和第14次选择；这是基于既有训练记录的开发设计。本轮不扫描16之外的长度，不因单候选、提前取得好方案或某种子表现改变长度。初始快照和完整WAIT认证仍由原构造器完成，不是策略可以跳过的免费前置。

启动新物理评价前，先只读重放旧直接窗口轨迹的前16个选择位置，比较Beam与6个固定BC/PPO在相同raw观测下的动作、完整计划和扩展前缀。各工况固定16槽，提前终止的槽位保留缺失。诊断只消费该位置以前的历史证据，不利用未来物理答案选点。动作分歧、不同计划和图目标上界只代表待检验机会，不等于物理收益；关键单候选位置不能归为学习选择成功。新轮的因果比较由下列完整冷任务提供，不仅依赖旧轨迹上离线打分。

## 64个冷任务及完整输出保护

每个工况有8个任务。每任务由独立冷父进程控制，EARLY与GUARD分别在新的隔离子进程执行；前一路真实退出后才启动后一路。原作者运行时仅允许每进程创建一次环境，保持此限制，不清理模块或复用运行时绕过。相邻两父任务并发后排空，各父任务最多一个活动物理子进程，故物理并发最多2。工况及初始方法槽按固定哈希排序，8个槽循环轮转，每槽在8个派发位置各出现一次。

| 方法 | 每工况任务数 | EARLY搜索 | GUARD搜索 |
|---|---:|---|---|
| 直接窗口参考 | 1 | coverage_v1窗口，全部由Beam选择 | 无 |
| 保护窗口规则 | 1 | 同上 | 独立完整原Beam |
| 保护BC | 3 | 前16扩展由相应固定BC选择，之后窗口Beam | 独立完整原Beam |
| 保护PPO | 3 | 前16扩展由相应固定PPO选择，之后窗口Beam | 独立完整原Beam |

EARLY保持原WindowBranchSearch候选可见性、特征、mask、认证、生成和停止规则。学习器只选择当前实际窗口中的branch，不新增特征、不改物理约束、不绕过失败验证。第16次扩展结束后切换共同Beam；未满16已结束则直接保留结束，不补足调用。

保护任务先完整执行EARLY，再在独立新环境、逻辑账、物理账和空缓存中执行原BranchSearch的完整Beam。两个搜索都从同一声明初态开始，不继承对方搜索状态或物理答案，不使用历史最终方案。GUARD不受EARLY消耗或结果改变，不能根据已知结果缩减保底。GUARD未来答案不进入EARLY的观察、候选、选择或停止。

仅当GUARD取得完整认证基线后才建立保护。最终在完整认证EARLY与GUARD方案之间按原认证正常供电能量严格择大，精确并列取GUARD；任何必要证据缺失保留科学失败，不能标为保护成功。保证针对同一30分钟规划指标，不包含计算等待的现实断供损失，也不代表连续暂态或所有硬件安全。EARLY阶段曲线仅代表已经取得的认证候选，不能提前宣称已有最终Beam下界。

## 每路预算及全部成本

每路独立使用原256逻辑点、最多256真实物理点、256扩展、256计划检查、5000候选、深度6、窗口32、Beam宽8和全部物理配置。两路都采用相同的精确电气输入等价缓存，但缓存仅限各路内部，不跨路、任务、方法或历史共享。

保护任务两路合计上限为512逻辑点、512真实点和512扩展，直接窗口参考为256；不能仍称两路合计256。独立初始化和失败调用全部计数。全轮56保护任务和8参考任务，共120条冷搜索，上限30720真实物理点；正常闭合时数值入口上限为120×3＋30720×4＝123240，异常按原始账本实际消耗统计，不以公式补造记录。

保护窗口、BC、PPO拥有相同两路额度，是介入位置的主要公平对照。直接窗口为现行部署参考，额度和保护结构不同，必须单列，不能把增加预算取得的质量自动归因算法。另报告EARLY路与直接窗口的同额度比较，但最终部署结论必须包含GUARD费用。

完整任务时间从控制器创建父进程至观察其真实退出，包含父/子进程启动、导入、输入核验、模型加载、两个环境与求解器初始化、搜索、模型推理、记录、关闭和封存。保存子进程派发、PID、真实退出、单调时钟边界及归一到父worker入口的检查点。路内阶段时间及完整worker时间另存。审计和存储维护时间不混入方法耗时；不从日志成本中扣出未经实测的部署加速。所有方法采用本轮共同的新记录方式，不能与上一轮旧记录方式的时间直接算加速比。

顶层preflight区间定义为父worker入口至EARLY子进程模型加载完成、物理计算开始的真实边界，包含父初检、派发、子进程导入和模型加载；它不是仅父进程初检。顶层computation从该边界计至父任务合并完成，包含后续EARLY、GUARD完整启动与运行、两路退出和父协调开销。GUARD不加载模型；EARLY模型加载是上述preflight的子集。子进程内部预检和阶段计时只作分项说明，不再叠加至完整时间。EARLY CLOSE边界早于该路最终序列化、封存和子进程退出，不能把它当作最终交付耗时。

## 记录、资源与独立核验

新驱动只减少重复存储：每路完整最终搜索记录保存一次，逐次选择保存开始/结束、候选与观测摘要、实际选择、模型值及响应；独立审计重建完整观测与mask并核对模型argmax。原始物理日志、请求和别名映射、全部认证计划、失败与异常保留，不能以压缩记录为由跳过证据。每个初始化和完成选择边界记录真实累计成本、认证能量与时间，保留前16块边界和全程终点。

逐选择仍保留实际推理使用的精简数值输入（候选特征、全局特征、mask和branch IDs）及其规范JSON摘要；摘要绑定实际输入字节含义，不把浮点重算的逐位一致当成额外物理假设。独立重建向量按既有审计数值比较口径核验，物理容差不改；固定模型对实际记录向量和独立重建向量必须选择相同动作，否则阻断。省略的只是可重建的重复关联矩阵及完整历史副本，不省略实际策略输入或必要物理证据。

首个新物理调用前冻结输入、全部传递源码、6模型、依赖、人口、派发顺序、协议和测试结果，并通过零求解预检。最大2worker、每任务3600秒、全轮14400秒合作式截止，磁盘底线12 GiB；执行前以既有逻辑日志量和本轮120路估算空间，附25%余量和2 GiB报告预留，运行时继续检查。发生来源、可靠性、未知成本、资源或实现错误时停止新派发，已有writer自然保存退出，不强杀、不自动重试、不删除记录换取继续。

独立审计不调用求解器，不以生产搜索实现作为重放依据。逐路核验原始物理证据、所有逻辑别名的因果来源、拓扑/电压/已知热约束/AC一致性、计划、窗口和共同停止；逐选择重建raw观测，核对前16学习动作和其后Beam规则。GUARD独立重放完整原Beam；核验两路隔离、全部成本、严格择大及全部64任务/8工况/3种子。未完成或有错误的任务全部进入汇总并报告覆盖，不能只报成功子集。

## 事前统计与判读

主比较为保护PPO对保护BC、保护窗口规则和直接窗口参考，另报告BC对规则。主均值先在同工况内平均三个种子，再对8工况等权平均；PPO—BC按同工况同seed配对，24配对不当作24个独立故障。保留每种子、每工况、平均、中位、最差差值和完整费用；1e−9个百分点仅用于描述并列，不能放宽保护能量下界。

同时报告最终认证质量、真实物理点、完整进程时间、前16块的终态及决策分歧、EARLY质量—真实点/时间曲线，以及包含GUARD实际费用的完整流程曲线。首次完整认证前为空缺，结束后如延长公共坐标只保持已取得结果并标注；不插值制造认证、不事后早停。来源已有质量可作为事前描述目标，但不能用于运行停止或模型观察。

本轮不给“超越”预填正结果。质量改善和成本改善分别判断：质量均值正差但更贵时报告质量—成本权衡；平均质量不低且真实点与完整时间均减少时才描述本轮平均效率改善。任一工况退化、种子不一致或指标权衡都同时呈现，不用平均值掩盖最差情况。只有相对窗口和BC的相应证据均成立，才能称在本轮范围内超过两者；不外推未见工况或论文录用。

若零求解诊断只显示无效分歧，完整小试仍可用于检验连续16步闭环是否产生新后继；不把诊断打分视作新训练标签。本轮结束不自动扩大训练或重新选择K。若仍无增量，应记录前移是否实际改变付费验证和认证路径，以及收益空间为何仍未被证实，再讨论新的决策设计。

主要比较PPO对共同优化窗口、PPO对同源BC：宏调度、候选机制、物理额度和保底相同，仅候选排序不同。deferred_window对interleaved_window检验整个调度时序及反馈进入下一展开的影响，不是单动作因果；PPO对interleaved_window同时包含调度和排序变化。旧完整窗口仅作历史背景，不用不同版本历史时间作为本轮加速分母。

保留64任务、全部种子、每工况4组汇总、逐种子及工况均值配对、完整及EARLY质量—实际点/worker时间阶梯曲线。先在每工况内平均3种子，再对8工况等权平均；报告质量百分点、真实点、完整时间的配对差、均值之比、胜/平/负和最差工况。缺失不补零、不略过；没有完成认证的任务不计为成功。全部失败、UNKNOWN与超时费用保留。单次小样本时间只作描述，不声称统计稳定或未见故障泛化。

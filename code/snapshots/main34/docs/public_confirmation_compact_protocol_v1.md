## 2 方法、输入与完整保护

P与E均复用已审计的分批候选、完整能量排序、精确电气证据服务、原物理认证和原Beam搜索核心。P按GUARD→EARLY运行并启用已认证完整目标的免费队列筛除；E按EARLY→GUARD运行，无未来GUARD证书。两者均完整执行原GUARD，最终仅在EARLY完整认证能量严格更高时替代GUARD，精确同值选择GUARD。

共同候选每任务生成一次，最多24个完整合法计划；窗口32，原覆盖规则不改。EARLY最多16 VERIFY和一次结束；原VERIFY内自身目标跳过和缓存命中仍消耗选择，失败不额外扩增候选。每逻辑阶段256点、每任务512真实点，一个冷物理运行时、任务内共享、任务间禁止共享数值答案。

网络、原整负荷、运行条件、设备、30个60秒槽、原30秒采样、CLPU表达式、图/电压/热/收敛/AC条件、alpha和后端算法均沿原封存来源。仅将预先固定的新故障与新事件按既有原解析规则精确投影，不拟合参数、不插值事件、不改变负荷或限制。新科学作用域显式绑定实际新输入和授权分区，不能冒用旧train-only作用域或历史缓存答案。

未完成GUARD、缺证书、UNKNOWN和实现/可靠性错误不能记作正常成功。被免费移除候选保持UNASSESSED；可靠物理FAIL、逻辑失败和执行异常分别记录。

## 3 两阶段执行前冻结

第一阶段只使用ID、已公开来源路径/原文件SHA、既有已见配置与合成软件测试，形成不可覆盖的设计冻结：包含本协议、24身份/48任务顺序、方法及驱动/独立审计/统计源码、物理继承契约、实际预算、环境、分析终点和继续授权说明。此阶段不使用新工况的物理响应或图成绩。

第一阶段同时固定原故障结构元数据（组合ID、故障线ID、阶数、分区与分区哈希），不含新电气值或成绩；第二阶段在设计冻结后，按上述固定ID读取并物化CLPU事件原值。所有读取动作、原来源和所选行/文件SHA留存，生成真实输入作用域、完整实际配置、依赖与源快照；不根据看到的参数修改算法、预算或样本。验证原解析来源、分区、单位、ID对应与原条件是否逐值保持，再形成物理执行前冻结并由独立核验器预检。

没有旧新工况历史GUARD成绩可供比较。本轮每个任务的GUARD必须从实际物理证据独立重放，P/E同工况再核对原GUARD科学轨迹和候选生成一致；明确没有调用历史新工况答案，不伪置history_verified为已由旧数据验证。前后源码或配置不一致、输入或依赖来源不明均阻止派发。

## 4 资源和实际顺序

48任务真实点总上限24,576，正常单初始化情形下数值入口上限98,448（48×3+4×24,576）。实际请求和入口仍据账本记录，异常不得机械套公式填值。

沿已测最大649,788.8131868131字节/真实点、1.25预测余量、12 GiB最低空闲和2 GiB报告预留，总所需空闲约32.591 GiB；物理前冻结及执行前再次测量。此判断不假定未知压缩比。每任务只计一次，已完成不重跑择优，不以实际点偏低为理由扩样。

为最小化新执行层，本版采用一个48任务总控制器、最多2个冷worker，相邻方法对排空后再派下一对；身份和臂轮转顺序事前固定。每worker最多900秒、总控制器最多3,600秒。该行政上限比收缩提案的8批累计8小时更紧，并非预期时长或每任务保证。本次不执行旧分阶段收益关卡，不依据中间质量决定是否继续。

容量、时间或可靠性边界触发停止派发并按控制器规则结束/排空在途任务，所有已执行和未开始身份保留，未知成本显式标识。无自动重试、换种子、补替或新增训练；故障修复如影响决策逻辑，必须新版本并说明已观察范围。

## 5 事前统计与措辞

主比较固定P对E；主要成本终点为实际物理点的24格均值比P/E，完整冷进程时间为必须报告的关键次终点。每格最终完整正常能量、归一化质量及其最坏差是不可省略的质量条件。全部24格等权，另列4故障均值、6事件均值、胜/平/负、最坏差、失败与缺失。相对节省采用`1−mean(P)/mean(E)`，不是逐格比率的平均。

若全部24对均有完整证书，且每对精确能量P≥E，才用“本固定组合集合上同质量或更高质量”表述。任何质量损失都报告质量—成本权衡，不改变非劣容差或隐藏最坏值。保底仅是本任务相对完整GUARD的保证，不能替代对E的效果比较。

使用固定seed20261024、10,000次双向簇重采样：独立有放回抽取4故障索引及6事件索引，以交叉重复权重共同重采样P/E，计算均值比/均差并取2.5%/97.5%分位数。仅4故障与6事件，区间解释受限，不能将24交叉格当24个独立故障或事件。PF比值区间上界严格小于1才支持预设区间口径的省点结论，跨1则保留不确定性；时间单次冷任务的区间不构成稳定现场延迟保证。

缺少必要的完整配对时，本版的全24格均值、比值和区间保持null，并列全部状态及真实成本；不能删除不完整样本后沿用全人口分母或成功标题。可以另外列已完成项的逐格观测，不把其当全人口结果。即使完整总体结果无优势，也不自动增加场景、预算或训练。

完整时间采用父进程记录的真实启动到退出，包含输入加载、构造、初始化、图处理、两阶段、证据共享、日志与关闭。独立核验、后处理和设计准备成本另列。阶段成本归属随执行顺序改变，不能把单阶段减少当完整节省，也不能与历史批次秒数混用。

## 6 论文用途及停止边界

本轮只检验固定公共机制从8已见开发工况到24预选组合的内部外推。既有A_prune条件消融继续作为开发机制证据，历史50%共享收益及5.41个百分点分批候选收益各自保留原批次，不与本轮相加。没有新增B、BC或PPO训练，不把公共收益改名为学习收益。

近邻文献适配仍按[可执行性报告](../reports/20261031_public_neighbor_feasibility.md)限定。未完成或不兼容的X不进入本轮比较，不将其静态反例、未求得解或未实现记成P的性能胜利。本轮完成也不自动证明算法原创性充分、对文献方法最优或SCI分区目标已达成。

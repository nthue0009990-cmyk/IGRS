# 同任务共享物理证据小试协议 v1

日期：2026-10-31。用户授权高效实现减少无效验证与重复成本、保留Beam保底的小规模对照。本轮先隔离公共共享机制，不训练、不调用BC/PPO，不将公共工程收益归因于强化学习。范围仅原8个已观察训练工况，不访问正式、tune或CLPU holdout。

## 固定来源与16任务

来源为已封存前期介入run `20261031T020246_028867Z_clpu_early_pilot`，根清单SHA `bed648a067dd82c3c52e0250de25714efcea7cca5b69347fad399e72e9e57747`。沿用全部8个protected_rule工况、事件、30时段模型、物理参数、完整认证标准与原BranchConfig。每工况各一个private和shared冷任务，共16个，不挑选困难样本、不删失败、不自动重试。原历史两路结果只用于独立语义核验，不供执行器取物理答案。

两模式均在单一冷进程只初始化一次原Nature34运行时，依次完整执行EARLY的coverage_v1窗口规则和GUARD的原BranchSearch Beam。各路逻辑账、语义缓存、搜索状态、256点预算与256扩展上限独立；private的电气证据池也独立，shared仅共享同任务内已发生且输入精确相等的电气证据。不同任务、工况、方法和历史间不共享。统一的新驱动和日志方式使本轮模式间时间可比；不得与旧双子进程时间直接计算因果加速比。

## 证据和输出保护

电气键使用既有精确等价键和冻结物理作用域，不四舍五入输入。原始证据只保存一次，逻辑引用保留来源事件序号、物理点ID和摘要；可靠PASS及FAIL在相同输入下复用，并在当前时刻重作纯认证。UNKNOWN、部分求解异常不得变为可靠FAIL或缓存成功，原失败反馈顺序不改。初始化、失败和部分数值调用均保留实际账本。

GUARD从相同初态完整运行，其逻辑轨迹应与private模式及既有完整Beam逐项相同。只在GUARD完全认证后建立保护；最终在两路完整认证方案间按原正常供电能量择大，精确并列取GUARD。未完成任务、缺认证、未知成本保留为失败/缺失，不宣布保护成立。本轮不引入新上界、早停、额外剪枝或推断物理安全。

## 执行与资源

事前固定工况哈希顺序，每对private/shared相邻，先后顺序各4次；最多两个物理worker，同时执行一对后排空再派下一对。单任务上限512实际点、512逻辑点，16任务总实际点上限8192；正常闭合数值入口上限16×3＋4×8192＝32816，异常按实际记录而非公式补造。

控制器时限3600秒，每worker900秒；到期不再派发，活动调用保留记录并退出。12 GiB空闲底线、2 GiB报告预留、历史最大每点存储量×剩余最坏点数×1.25的预测，均为执行资源设置而非物理参数。单线程数值环境、无可见后台窗口。计时区间不并行运行其他重型测试或诊断。

首求解前独立runs目录冻结本协议、实际配置、全部源文件、依赖、解释器、种子0、人口、统计口径、预算及通过的联合组件测试XML。此前失败的软件检查及原科学记录不改写。

## 统计与结束条件

主要检查为8对语义与完整认证质量相等、真实物理点减少，以及冷进程从创建至实际退出的完整时间变化。时间包含输入核验、初始化、两个搜索、共享检查、记录、封存和进程退出；另报告逻辑点、数值入口、阶段时间及失败点，不以缓存命中次数替代实际节省。

保留16任务表、8配对、每工况结果及完整检查点曲线。模式均值按8工况等权；百分比变化使用均值之比，差值用shared减private，并报告最差工况和不利结果。缺少认证时质量为空，不补零或删样本。小样本单次时延仅作描述，不能称稳定泛化提速。

全部实际退出与成本核对后，独立重放原始物理证据、双逻辑引用和两路搜索，再生成报告、封存与全工况图。真实收益与局限分别报告。即使本轮通过，也未证明PPO超过相同优化窗口与BC；只有后续最小决策探针显示额外可兑现收益，才另立冻结协议考虑新学习动作和训练。并行全时域图上界诊断为零求解独立产物，其结果不影响本轮人口、预算和停止规则。

# LazySP槽边选择组件：固定开发小对照 v1

2026-11-01。承接用户“赶紧解决贡献定位和外部对照”的授权。此批只判断一个保留文献算法核心的外部搜索组件是否可在共同恢复任务上公平比较；不改变公共P、原物理模型、参数或已封存实验，不训练，不重开大型MILP。

## 事前固定范围

使用原公共机制开发批的c00、c02、c04、c07：覆盖既有非分批案例和两个同故障不同事件的困难案例。这是已知开发工况的小型接入对照，选样受已有研究历史影响，不称新独立测试，不估计总体泛化。四例均保留，不以新结果替换。各执行P、LazySP-Forward、LazySP-Reverse各一个冷任务，共12项；三臂同批计时，旧P/E时间不作本批分母。

LazySP来源为Dellin–Srinivasa《A Unifying Formalism for Shortest Path Problems with Expensive Edge Evaluations via Lazy Best-First Search》，Algorithm 1及Algorithm 2。使用原文Forward和Reverse两个确定选择器，不调参或按结果择优保留一个。名称为“LazySP槽边选择的CLPU组件适配”，不称文献完整配电恢复算法、最新SOTA或作者原实验复现。

## 保留与适配

各臂先付费完整执行原BranchSearch Beam GUARD，随后付原INITIAL/完整WAIT bootstrap并生成完全相同的固定分批候选族。物理oracle、精确同任务缓存、每步合法/森林/不中断供电、30×60秒时域及每槽起点/30秒/60秒采样全部不变。P使用原GuardFirstStagedSearch与原控制器，不修改搜索规则。

LazySP把完整动作序列展开为前缀树，一条边对应一个动作槽和其完整恢复历史；不同前缀不按仅开关状态合并，不产生候选族外新路径。每边乐观代价为该槽正常未供电能量，可靠PASS保留原值、可靠FAIL取无穷大，UNKNOWN立即作为可靠性问题停止，不冒充FAIL。所有完整候选均进入选择范围；平局规则与原完整能量选择器一致，为完整能量降序、branch_id升序（不混同P免费筛除使用的完整priority键）。已付费GUARD作为完整认证参照，只在候选主能量严格更高时继续，不将基线证据免费赠送给任何臂。

Forward选择当前最优未排除完整路径的第一条未认证边，Reverse选择最后一条未认证边。边内部仍按原三个采样顺序认证，任一可靠FAIL阻断该边及包含此相同前缀的候选。乱序认证不是乱序执行操作；状态/首次复电历史通过纯图前缀完整计算，物理模型每次独立重置。完整路径通过后仍调用原validate_plan重建规范完整证书，缓存、请求数和逻辑费用全部记录。

原P有交替候选曝光，而LazySP按全候选最短路径选择；这种区别是算法干预，应公开，不伪称二者验证顺序相同。最多开始验证16条不同候选；边选择次数另外记录，不把16次边检查冒称16次完整VERIFY。预算终止只保留已有完整认证输出，不称候选族最优；无截断且所有剩余路径界不优于证书时，最优性也只限当前固定候选族。

## 资源、冻结和停止规则

每阶段256唯一逻辑点、每任务512真实物理点，总真实上限6144；全部失败、初始化、缓存和候选生成计费。每任务完整冷进程180秒、全控制器2400秒、单worker串行，三个轮次轮换臂的先后次序，固定seed0，不加载模型。完整耗时从创建冷进程前计至退出后，包括配置核对、导入、搜索、日志及封存。

运行前冻结全部配置、12身份、源码与依赖；独立核对新组件及原预算/证书接口，通过后方可启动。执行后所有12项保留，无自动重试、续试或选例删失。任一异常/未知、预算计数矛盾、完整证书不闭合或物理身份问题停止后续任务，保留日志并按项目约束报告。程序失败不以Beam存在掩盖为算法成功。

## 统计及结论

全部四例等权逐对报告：完整正常供电质量、实际点、完整冷耗时、可靠PASS/FAIL、失败/缺失、候选池一致、GUARD科学轨迹一致与保底。P分别对Forward和Reverse报告，不选择较弱者作为唯一结论。节省使用均值比；只做描述性结果，不在4例上增加显著性检验，不混入旧批次均值。任一未完成时不发布全四例胜率或总体优势。持平、P落后或外部组件质量更高均照实保留。

LazySP适配在边验证后另用原validate_plan重建规范证书，这会对成功候选产生90次额外逻辑请求（应全部命中已有证据，不新增真实物理点）。这些请求和CPU费用照计，单列其次数；时间差只能解释为当前完整实现的差异，不能宣称原LazySP算法固有地更慢。外部比较优先依据最终质量与实际物理点；不利用额外证书整理开销包装新的求解优势。

本批只能补上共同候选族内的通用昂贵验证搜索对照，不能替代最近配电CLPU完整方法的数值复现。若P与LazySP持平，应明确P相对E的成本优势可以被已知懒搜索机制解释，收窄创新主张；不再为制造胜利添加训练、改权重、删样本或重新命名算法。

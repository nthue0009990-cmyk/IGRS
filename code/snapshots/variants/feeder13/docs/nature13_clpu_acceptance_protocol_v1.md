每个查询先保存请求，再执行并保存原始输出、设备读回、拓扑、隔离、AC、电压、热约束、DER检查及完整调用日志。可靠约束FAIL与数值/证据UNKNOWN严格分开；不以填零、删除节点或静默关闭设备处理异常。

- 新初态若可靠约束FAIL，保留该点并停止；该批无法取得全部完整等待基线，不执行后续方法比较，不用其他故障替换。
- 新峰值的可靠电压/热/已知DER约束FAIL是有效验证结果，可继续原剩余查询；不强求16点均合规。其数值或证据可靠性失败仍停止。
- 同一状态两算法按原交叉容差比较；带电范围及停用设备的数值缓存边界由冻结的独立比对函数决定，不比较已证明无物理意义的停用缓存，也不合成观测。跨算法不一致属于入口可靠性失败。
- 每个新初态的Normal结果须形成30槽、每槽3采样的完整等待证书。90条逻辑记录逐条核对真实输入等价、当前历史与来源；不能用一个初态PASS标签替代完整覆盖。全部共享只发生于该入口验收，不预置到后续方法冷任务。

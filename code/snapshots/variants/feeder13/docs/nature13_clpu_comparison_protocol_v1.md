## 预先固定的报告规则

每个组合必须报告三法最终正常供电能量/质量、GUARD能量、最终动作、完整证书覆盖、实际物理查询、唯一逻辑点、数值入口、完整冷时间、可靠FAIL、UNKNOWN、预算或异常退出。所有六组合等权；不把当前入口的峰值失败当作P/E/Forward方法失败。

主比较为P/E，P/Forward为强组件检查，两者同表报告。先逐组合检查最终能量是否相同；仅当全部配对质量相同时，才使用“同质量成本节省”。实际点和完整时间的节省率均为`1−sum(P)/sum(对照)`，同时报告逐例差值、胜/平/负与最坏值。质量不同则报告质量—成本权衡，不用删例、四舍五入成相等或调整容差制造同质量优势。

在相同查询上限下质量更高，可以报告有限预算质量收益，并同时报告完整时间；质量相同且完整时间更低，可以报告平均完整成本优势。只少物理点但完整时间更长，应明确为验证次数与耗时的权衡。P/Forward持平也是有效结果，不通过另换窗口或追加训练求胜。

仅3故障×2事件，不作显著性检验或泛化概率推断。任一任务未完成，则全部18项状态照列，六组合完整配对均值不得以剩余幸存组合替代；可另给明确标注的已完成部分描述。可靠FAIL保留；UNKNOWN、隔离/AC/来源/读回问题停止受影响工作，不能改成物理FAIL继续。

结果只支持具名三相模型及采样范围的开发迁移，不声称大规模扩展、连续时间安全或完整领域方法领先。不同版本/网络的节省百分比不相加。

# 已发表改进 Viterbi 与 IGRS 的单合联络线共同子问题

本开发比较仅覆盖 Yuan、Illindala 与 Khalsa 的修改 Viterbi 算法中“故障已断环，单合联络线”的分支。两臂锁定原五个分段开关和十个负荷准备位，只可合上尚未动作的四条联络线，每分钟一步、禁止成环与再次断供；结束动作后等待至原30分钟，连续动作之间不另设等待。恢复曲线、故障、负荷、OpenDSS、每时隙三点、初始检查和所有限值沿用同一开发基准。在每个完整动作方案上均得到相同定义的正常供电积分。文献法保留按终态恢复负荷、开关数、电压与损耗的选择规则，另报受保护结果；IGRS按正常服务积分择优。二者原生目标不相同。完整论文中的成对开闭、DG独立成岛、组负荷控制不属于本对照。

零物理求解的准入规则是：在原八个有编号的开发工况中找出图上确有两个连续单合、每步均新增正常供电的工况，按原编号取首两例，无结果替换。图上准入结果为 c03/l21+l30/事件3 和 c06/l17+l29/事件6，每例均有5个不同完整动作串（含等待），其余6例只允许零或一个单合。两例为开发接口和机制验证，不能估计未见故障总体收益。

两臂均先在相同动作语法下运行原有宽度8的 Beam。图启发补全按剩余深度、相同正常功率目标在受限图上计算；Beam费用计入各自独立任务。IGRS的原批量筛选与控制器读取受限动作语言中的全部非空合法联络线顺序，完整计划/目标/样点认证规则保持。原分批生成器在锁定所有准备位后不能工作，因此替换为这个可完整列举的小池；这一臂称“IGRS 共同子问题适配”。外部臂采用论文单合格形图规则的独立Python重实现。它只接触自己当前求解阶段已付费的数据，在格形图过渡时只检查截至最近操作槽末的历史样点，按原法选定唯一序列后补等待并完整检查30分钟，在状态排序使用最后一次合闸槽起点的最低已带电相电压和三相有功损耗，同状态同电气指标用动作ID稳定破同。若被选方案的等待尾段失败则登记该策略原生可交付结果缺失，保底保留，不自动试下一候选；同拓扑不同复电历史分别求值。外部臂不使用Beam方案做格形图排序。最终分别登记外部法自己的计划、受保护路径、终态正常kW、操作次数、正常kWh、完整实际查询、逻辑点和整任务进程秒；合并只接受严格提高已认证正常kWh的方案，否则保留Beam。用闭合数、原生终态kW、统一30分钟kWh解释排序差别。

每任务独立冷进程、无跨任务缓存、GUARD/EARLY各256逻辑点，合计512实际物理点，最多240秒；IGRS支持16次追加选择，文献法单合树每例至多4条非空前缀；两者均可评估全部这些候选，无额外赠送物理结果。外部原生输出已获得共同阶段的缓存，单独的外部阶段耗时/查询不等于无保底外部算法的独立冷成本。两个工况轮换两臂启动顺序，串行无训练。所有可靠越限保留；物理未知、预算不足阻碍完成、超时、绑定错误均结束本轮，不换例、不自动重跑。序列是否出现至少两步、是否通过全时域及多方法是否有质量/成本差值直接按各例报告，不因数量小宣称领先。

执行前使用无求解软件测试和静态预检：原参数/依赖/物理源散列相同，8身份及候选池重算一致，Beam合并额度不残留256限制，预算耗尽与可靠FAIL不被当数值未知。执行遇到可靠约束FAIL照原搜索继续；数值UNKNOWN、隔离/证据/接口异常、超时或任务失败则保留记录并停止后续任务，不追加预算。不把不完整任务记成成功或物理无解。所有实际点保存原数值证据，后审重算已知物理检查、复用因果关系、原搜索决策和成本，不新增潮流。
